Frequently Asked Questions

Does RanchMaster work without cell service?
Yes. All herd, field, feeding, and event data is stored locally on your iPhone or iPad first. Changes sync automatically via iCloud when you return to signal.

How do I invite my crew?
Open your ranch, go to More → Crew → Invite Crew, and send an invitation via Messages, Mail, or AirDrop. You can set each person to Can make changes or View only. Crew members only need RanchMaster and an Apple Account.

Which EID readers are supported?
RanchMaster supports 15-digit CCIA RFID tags via Bluetooth keyboard-style wands (in Sort → EID Reader) and Bluetooth LE readers using the Nordic UART service (paired under More → EID Reader).

How do I export my records?
Go to More → Traceability → Export to generate an Excel workbook (.xlsx), CSV files, a Year-End Summary PDF, or a CLTS traceability CSV.
